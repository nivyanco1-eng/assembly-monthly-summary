# מחולל סיכום חודשי – מפעל ההרכבות

דף A4 חודשי למפעל ההרכבות של SodaStream: PAP, CR, COPQ, אירועי בטיחות, EFFICIENCY ו-HC, עם הערות כלליות, היסטוריה לפי חודשים והורדה כ-PDF.

הנתונים נשמרים ב-Firebase Realtime Database (הכתובת מוגדרת ב-`FIREBASE_URL` בתוך `index.html`, תחת הענף `assembly-monthly`).
